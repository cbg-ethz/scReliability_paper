# Data

The raw data are **not** redistributed here (they belong to the original studies
and are large, ~67 GB). Download them and place them under this `data/` directory
(or point the `SCRELIABILITY_ROOT` environment variable at a directory that
contains a populated `data/`).

Expected layout:

```
data/
  Wei_et_al_data/
    genetic_context_preprocessed_h5ad/      # per-dataset .h5ad (genetic CRISPR + sci-Plex), ~50 GB
    cellular_context_preprocessed_h5ad/     # per-dataset .h5ad (cellular contexts), ~18 GB
    Results_from_original_study/            # the Wei et al. benchmark score CSVs, ~94 MB
  Ahlmann-Eltze_data/
    Source Data Fig.2.xlsx                  # AE benchmark (single perturbations)
    Source Data Fig.4.xlsx                  # AE benchmark (double perturbations)
  genesets/
    genesets.json                           # Hallmark library, used by the shared/specific GSEA
    genesets_GO_Biological_Process_2023.json  # 5,407 GO BP terms
    ens2sym_sciplex3_comb.json                # ENSEMBL -> symbol map for sciplex3_comb (mygene, 4,975 genes)
```

Two of the three files under `genesets/` are Enrichr gene-set libraries fetched by `blitzgsea`,
totalling ~4 MB. The library names pin the version, so both can be re-fetched rather than copied.

`genesets.json` supplies the Hallmark library, read by `scripts/05_shared_specific/contexts.py`
and `gsea_axis_raw.py`:

```python
import blitzgsea as blitz, json
json.dump({"Hallmark": blitz.enrichr.get_library("MSigDB_Hallmark_2020")},
          open("data/genesets/genesets.json", "w"))
```

`genesets_GO_Biological_Process_2023.json` is the flat GO BP library, read by `gsea_axis_GOBP.py`
and `add_sciplex3_comb.py`:

```python
import blitzgsea as blitz, json
json.dump(blitz.enrichr.get_library("GO_Biological_Process_2023"),
          open("data/genesets/genesets_GO_Biological_Process_2023.json", "w"))
```

## Sources

**Wei et al.**, *Benchmarking algorithms for generalizable single-cell perturbation
response prediction*, Nature Methods 2026;23:451-464.
<https://doi.org/10.1038/s41592-025-02980-0> — code at
<https://github.com/bm2-lab/scPerturBench>.

- Preprocessed `.h5ad` datasets: Figshare
  [cellular](https://doi.org/10.6084/m9.figshare.28143422) /
  [perturbation](https://doi.org/10.6084/m9.figshare.28147883), or Zenodo
  [cellular](https://doi.org/10.5281/zenodo.14607156) /
  [perturbation](https://doi.org/10.5281/zenodo.14638779).
- Per-perturbation benchmark scores (`Results_from_original_study/`): downloadable from their
  reproducibility site, <https://bm2-lab.github.io/scPerturBench-reproducibility/>.

**Ahlmann-Eltze et al.**, *Deep learning-based predictions of gene perturbation effects
do not yet outperform simple linear baselines*, Nature Methods 2025.
<https://doi.org/10.1038/s41592-025-02772-6> — code archived at
<https://doi.org/10.5281/zenodo.14832393>.

- `Source Data Fig.2.xlsx` and `Source Data Fig.4.xlsx` are the Source Data files
  published with that paper.

Both benchmarks' score tables are used **verbatim**: this repository re-labels their
perturbations by reliability class, it does not recompute their metrics. A join of our
merged table against `genetic_single_performance_top100.csv` matches 26,700
(method, dataset, perturbation) groups with a maximum absolute difference of 0 across
all six metrics.

Only the code is version-controlled; everything under `data/`, `output/`,
`intermediate/`, `results/`, and `figures/` is git-ignored and regenerated by the
pipeline (see the top-level `README.md` and `run_all.sh`).
